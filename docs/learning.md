# 设计判断与学习记录

## 契约与生成

SQL 是数据库正本，Prisma 从迁移后的空库反向生成，避免两套模型逐渐分离。API 正本是 Zod/OpenAPI 路由定义，生成 Axios Client 与参考文档；前端表单复用纯输入 Schema。页面契约生成参考说明并检查真实路由/E2E 对应。生成检查与业务测试分别验证结构一致和实际行为。

当前生成器覆盖项目的 8 个 JSON 操作，并不承诺任意第三方 OpenAPI；TypeScript 编译 API 工具单独固定 5.9.3，应用使用计划中的 TypeScript 7。详见 [API 指南](./api.md)。

## 订单、幂等与锁

草稿保存价格快照但不预留库存。确认订单在同一事务内更新库存与状态；取消已确认订单同样原子返还。先锁订单、再按商品 UUID 排序行锁，减少多商品互锁。重复确认/取消返回已有结果，创建用 owner/key advisory lock 保持同 key 幂等。

生产使用悲观锁。仅测试的 xmin 乐观 CAS 演示冲突与重读后重试，不作为生产版本字段；真实重复提交、竞争、回滚和有限重试通过 SQL 故障注入与可观察锁等待验证。边界见 [重点验证](./verification.md)，实现见 [订单说明](./orders.md)。

## 认证与环境

API 验证 access token 的签名与用途，管理权限检查 admin 组，订单读取把所有者条件放到 SQL。前端可提示权限但不能代替后端授权。模拟器负责本地可复现，生产禁止 local 模式；部署仍需真实 Cognito 与注入配置。

开发与 CI 使用容器固定工具版本，关闭 .env 隐式加载。文档增加 VitePress 1.6.4，应用继续使用 Vite 8；根工具链固定 esbuild 0.28.2，满足应用 Vite 的 peer 要求，VitePress 自带的 Vite 5 保留自己的 esbuild。文档配置使用 envDir:false，构建检查站内死链接，仅对明确的本地服务地址例外。本地搜索帮助新人查找生成参考和启动流程。
