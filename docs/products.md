# 商品功能

Step10 已实现管理商品注册/列表、公开代码和名称搜索、库存查询及网页展示。private 商品 API 经 Cognito access token 和 admin 组校验；公开搜索和库存允许访客。所有业务响应仍经过 Step7 的发送前验证。

注册通过契约的 Zod 输入验证和规范化后写入 Prisma，价格由 number 转为 bigint 存储；响应只返回显式 DTO。数据库唯一约束处理并发代码冲突，P2002 转为契约内的 409 DUPLICATE_PRODUCT，不返回数据库细节。输入错误或无权限时不写入商品。

代码 trim/uppercase 后完全匹配，名称 trim 后不区分大小写的字面子串匹配，组合采用 AND。Prisma ILIKE 的反斜杠、百分号、下划线均转义；不把用户搜索当 SQL 通配符。列表按代码升序，默认每页20。count 和分页查询在 RepeatableRead 事务中保持同一快照；大到超出安全 offset 的末页之外请求也返回空页，不转换成溢出 SQL 参数。

前端包含商品说明、JPY 价格、库存、搜索与分页。注册201后返回管理列表，409时保留表单。买家可刷新当前库存，使用 TanStack Query setQueryData 更新缓存，避免修改只读数据；库存仍是快照，不构成预留。订单在 Step11 实现。

仅新增一个组合数据库/API测试与一个真实浏览器场景。API测试用独立临时PostgreSQL验证 AC-P01〜P06，含权限、重复代码、不写入非法输入、Unicode长度、字面特殊字符及分页/库存。浏览器管理员注册唯一 E2E 代码的真实商品，验证重复冲突、买家搜索、纯文本说明、空结果及连接失败；测试夹具在数据库将该商品库存改为9，再验证刷新显示9。开发浏览器测试生成少量 E2E-* 商品，CI数据库为临时服务。
